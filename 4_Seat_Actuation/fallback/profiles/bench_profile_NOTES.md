# 벤치 압력 프로파일 분석 노트

> `bench_profile.json`은 벤치 실험에서 측정한 ADC 분포와 명령한 모터 상태를 정리한, 규칙 기반 제어 개발용 **경험적 참조표**입니다.
> 각도 → 힘 보정, 단조 증가하는 압력 이득, 인체 접촉 안전 한계를 정하지는 않습니다.

---

## 1. 원본 데이터와 제외 항목

| 항목 | 내용 |
|---|---|
| 데이터셋 | `bench_pose_v1` |
| 프로파일 세션 | `S08` — 좌우 독립 Yaw 0~27°, 양쪽 Pitch 0° |
| 비교 세션 | `S07` — 왼쪽 Yaw 0~20° / Pitch ±8°, 오른쪽 0° |
| 추가 조사 세션 | `S06` — 좌우 동일 Yaw 0~20° / Pitch ±8° |
| 측정점 | 357 + 357 + 784. 세션마다 네 각도 조합을 한 번씩만 방문 |

- 측정점들은 무작위 반복 시행이나 4차원 전체 보정이 아닙니다.
- 아카이브에서 필요한 항목만 골라 읽었고, 항목별 ZIP CRC 검사와 로컬 SHA256 출처 기록을 남깁니다.
- 영상, 이미지, 프레임 표, 랜드마크, 추정 자세, 자세·압력 병합 표는 **사용하지 않았습니다**.
- `points_source.parquet`는 원래의 모터 실험 결과표입니다. 빌더는 모터·압력·시간 열만 명시적으로 선택하고 영상 개수 열은 제외합니다. 실험 메타데이터는 설정·시계·출처 확인에만 씁니다.
- 원시 추출 파일은 `<data dir>`에 두며 Git에 포함하지 않습니다. 각 원본 파일의 경로·바이트 수·SHA256은 JSON의 `provenance`에 기록합니다.

## 2. 측정값의 의미

| 항목 | 의미 |
|---|---|
| 채널 이름 `A0_C0` … `A2_C3` | ADC 뱅크와 MUX 입력 번호. 이름만으로 좌/우, 상/하, 접촉 면적을 추정하지 않음 |
| 값 | `raw × 3.3 / 4095` 추정 전압(V). Vref는 명목값이며 측정값 아님. N, kg, kPa 단위가 아님 |
| 기준점 | 명령 (0,0,0,0)에서의 값은 해당 세션의 **착석·접촉 상태 기준**이며 무부하 ADC 영점이 아님 |
| `p05_v`, `p50_v`, `p95_v` | 각 2초 측정 구간 안 유효 원시 ADC 값의 표본 분위수(NumPy linear). 신뢰구간이나 안전 기준이 아님 |

채널별 p95를 더한 값은 합계의 p95가 아닙니다.

## 3. 하드웨어 구성 일치 조건

원본 실험의 구성은 DS5180SSG 270° 서보, C4_R8 역기구학, 크랭크 영점 1200 µs이며 영점 명령 PWM은 다음과 같습니다(측정 스테이션용 `OASIS_CONTROL v6` 영점과 같음).

| 핀 | 관절 | 영점 PWM | 방향 |
|---|---|---:|---:|
| D3 | 오른쪽 크랭크 1 | 1800 µs | −1 |
| D4 | 왼쪽 크랭크 1 | 1200 µs | +1 |
| D5 | 오른쪽 크랭크 2 | 1200 µs | +1 |
| D6 | 왼쪽 크랭크 2 | 1800 µs | −1 |

- 최종 `OASIS_FALLBACK v2` 펌웨어는 현재 장착에 맞춰 보정한 영점 D3/D4/D5/D6 = 1800/1800/1200/1200 µs를 씁니다. 이 프로파일은 위 v6 영점으로 기록되었습니다.
- 이 구성은 이전의 180° 구동·조립 중심 1500 µs × 4 가정과 다릅니다. 두 구성 사이에서 프로파일을 그대로 옮겨 쓰면 안 됩니다.
- 실제 축·판 위치는 측정하지 않았습니다. 기록의 `arrived`, `moving` 필드는 제어기 **명령 상태**입니다.
- 독립 Yaw 실험의 PWM 범위는 D3/D6 = 1296~1800 µs, D4/D5 = 1200~1704 µs입니다. 관측 최대 Yaw 27°는 데이터셋의 경계이며, 별도로 검증한 간섭·접촉 한계가 아닙니다.

## 4. 프로파일 부분집합 검증

JSON은 왼쪽 단독·오른쪽 단독 분기를 가지며 각각 Yaw 0~27°, 1° 간격입니다. 공통 영점을 합치면 고유 명령점은 **55개**이고, 반대쪽 Yaw와 양쪽 Pitch는 0입니다.

| 검사 | 결과 |
|---|---|
| 유효 ADC 값 | 132,660개 = 55점 × 12채널 × 201개 |
| 시간 구성 | 모든 점에서 도달 보고 후 정확히 0.5초 뒤 측정 시작, 2초 반열린 측정 구간 |
| 모터 상태 | 측정 구간 안 상태 보고 10개 모두 armed=1, moving=0, fault=NONE, 현재·목표 명령각 일치, 예상·보고 PWM 일치 |
| ADC | 오류·포화 0 |
| 평균 재계산 | 제공된 `point_pressure.csv`와 차이 1e−10 V 미만 |

`motion_check`와 채널별 표본·품질 필드가 이 근거를 보존합니다. 텔레메트리 일관성을 확인한 것이며, 물리적 위치를 측정한 것은 아닙니다.

## 5. 압력 응답은 단조가 아님

단독 분기에서 Yaw 0° → 27°의 평균 변화:

| ADC 채널 | 왼쪽 단독 Yaw | 오른쪽 단독 Yaw |
|---|---:|---:|
| A1_C0 | +0.032 V | −0.093 V |
| A1_C1 | +0.156 V | −0.021 V |
| A1_C2 | −0.443 V | −0.101 V |
| A1_C3 | −0.202 V | −0.295 V |

- 프로파일에는 가중 증가·감소 PAVA 적합과 잔차가 들어 있지만, 어느 쪽도 구동 극성이나 인과적 압력 이득을 입증하지 않습니다. 예를 들어 왼쪽 단독 A1_C2의 증가 적합은 평탄하고, A1_C3는 두 분기 모두 중립 p95보다 큰 측정점 p95가 없습니다.
- 따라서 "Yaw를 늘리면 압력이 늘어난다"고 가정한 적분 제어기는 출력 한계에 걸릴 수 있습니다.
- 프로파일은 **외삽 없는 경험적 참조표**로만 씁니다. 압력 피드백은 새로 잡은 기준선 대비 증가량이 설정 한계를 넘을 때 명령을 **제한·차단**하는 데 쓰며, 가정한 압력 목표를 따라 Yaw를 계속 올리는 데 쓰지 않습니다.

## 6. 세션 간 변동과 미측정 히스테리시스

| 비교 (같은 명령의 평균 절대 차이) | A0_C3 중앙값 / 최대 | A1_C0 중앙값 |
|---|---|---|
| `S06` vs `S08`, 공통 명령 21개 | 0.542 V / 0.999 V | 0.322 V |
| `S07`(왼쪽 단독) vs `S08` | 0.544 V / — | 0.402 V |

- 활성 채널의 구간 내 표준편차는 대체로 0.03~0.04 V로, 세션 간 차이가 훨씬 큽니다. 측정 잡음만으로 볼 수 없습니다.
- 착석자·접촉 변화, 예압, 드리프트, 스캔 순서, 히스테리시스는 독립적으로 통제·식별되지 않았고, 명령마다 세션당 1회만 방문했으므로 이 데이터로는 구분할 수 없습니다.
- 압력 증가량을 쓰기 전에 **현재 중립·접촉 기준선을 다시 측정**합니다. 이전 세션의 절대 전압을 새 착석자의 압력 목표로 쓰지 않습니다.
- A2_C0, A2_C3는 대부분 0 근처입니다. 신호가 낮다는 것만으로 고장이나 비착석을 단정하지 않습니다.

## 7. 초기 운용 후보값 (안전 한계 아님)

| 후보 | 산출 | 의미 |
|---|---|---|
| 초기 Yaw 후보 5° (`initial_angle_candidate_deg`) | 관측 범위 0~27°의 20%를 내림 | 보수적인 소프트웨어 초기값. 하드웨어·구성·간섭 확인 필요 |
| 채널별 압력 증가 후보 | 같은 분기에서 기준 p95와 최대 측정점 p95 사이 양의 범위 × 20% (범위가 0이면 0) | 보정된 압력 한계·양의 이득 근거가 아님 |

런타임 제어기는 별도의 각도·변화율·신선도·피드백 제한을 적용해야 합니다.

## 8. 재현 방법

오프라인 빌더는 NumPy와 PyArrow가 필요하며, JSON을 읽는 쪽은 PyArrow가 필요 없습니다. 데이터 폴더는 `raw/bench_pose_v1/<session>/...` 구조이며, `analysis_deps`에 PyArrow를 분리 설치할 수 있습니다.

```powershell
# fallback 폴더에서
python build_bench_profile.py --dataset-dir <data dir>\bench_pose_v1 --output profiles\bench_profile.json
python -m unittest discover -s tests -p test_bench_profile.py -v
```

- `--pyarrow-dir <data dir>\analysis_deps`로 오프라인 의존성을 분리할 수 있습니다.
- 빌더는 허용 목록의 압력·모터 파일과 명시한 열만 읽습니다.
- 시험 4개: 가중 병합·잘못된 입력, 분기 완전성, 표본 분위수 순서, 텔레메트리 근거, 단조 적합 일관성, 후보값과 안전 한계의 분리.

실제 운용 전에 필요한 입력: 채널 ↔ 시트 위치 매핑, 서보·마운트·영점이 이 벤치 실험과 같다는 확인, 현재 중립·접촉 기준선. 이 정보는 영상이나 채널 이름에서 복원할 수 없습니다.

## 9. 센서 위치 매핑과 구동 방향

조립 확인으로 얻은 측면 센서의 물리적 위치(착석자 기준):

| 채널 | 위치 | 쪽 |
|---|---|---|
| A1_C0 | DR, 오른쪽 아래 | 오른쪽 |
| A1_C1 | UR, 오른쪽 위 | 오른쪽 |
| A1_C2 | DL, 왼쪽 아래 | 왼쪽 |
| A1_C3 | UL, 왼쪽 위 | 왼쪽 |

- 마운트·혼·링크·센서는 벤치 실험 이후 변경되지 않았고, 기록된 실험 중 불편감이나 걸림은 관찰되지 않았습니다.
- **양의 Yaw(0 → 27°)는 양쪽 볼스터 모두 몸 쪽으로 닫는 방향**입니다.
- 이는 조립·관찰 확인이며 힘 보정, 엔코더 측정, 일반적인 안전 접촉 한계를 제공하지 않습니다. 착석자, 중립 접촉 기준선, 초기 동작 확인은 실제 세션에서 다시 점검합니다.
- 원본 `bench_profile.json`은 출처 보존을 위해 매핑 필드를 "미상"으로 유지합니다. 매핑을 적용한 분석은 [`mapped_analysis.json`](mapped_analysis.json)에 별도로 기록합니다(원본 해시, 공통 중립 포함 56개 분기 행, 부호 있는 변화량, 표본 통계, 원래 측정 시간, 이전 세션 비교). 이 매핑에 영상·자세 기반 근거는 쓰지 않았습니다.

### 9.1 매핑 기준 부호 있는 응답

아래 값은 매핑된 두 채널 **평균의 합**을 그 세션의 착석 중립 대비로 나타낸 것입니다. 전기적 요약이며 총 접촉력이나 합계의 분위수가 아닙니다. MUX 채널은 같은 구간 안에서 순차 샘플링되므로 공분산과 합의 분산은 추정하지 않습니다.

| 단독 Yaw 명령 | 왼쪽 평균 전압 합 변화 | 오른쪽 평균 전압 합 변화 |
|---|---:|---:|
| 왼쪽 1°, 오른쪽 0 | −0.5491 V | +0.0616 V |
| 왼쪽 5°, 오른쪽 0 | −0.5232 V | +0.0392 V |
| 왼쪽 27°, 오른쪽 0 | −0.6448 V | +0.1882 V |
| 오른쪽 1°, 왼쪽 0 | −0.1418 V | −0.0158 V |
| 오른쪽 5°, 왼쪽 0 | −0.9022 V | +0.1109 V |
| 오른쪽 27°, 왼쪽 0 | −0.3957 V | −0.1146 V |

- `S08`에서는 두 독립 분기의 모든 0이 아닌 점에서 왼쪽 매핑 합이 공통 중립보다 낮습니다.
- 오른쪽 변화는 단조가 아니며, 첫 양의 오른쪽 Yaw가 오른쪽 합을 늘리지 않습니다.
- 채널별 과거 p95 최대값을 평균하면 이런 음의 변화가 가려지고 서로 다른 각도의 최고점이 섞입니다. 그 값은 **상한 감시 범위**로는 쓸 수 있지만, 압력 응답 모델로 역산할 수는 없습니다.

이 결과가 구동 방향 확인과 모순되거나 "닫으면 압력이 준다"를 입증하는 것은 아닙니다. 실험이 각도를 시간·접촉 변화와 분리하지 않았기 때문입니다. 이전 왼쪽 단독 세션(`S07`)에서는 같은 명령이 반대 부호를 보였습니다.

| 왼쪽 Yaw (나머지 0) | `S07` 왼쪽 합 변화 | `S08` 왼쪽 합 변화 |
|---|---:|---:|
| 1° | +0.7896 V | −0.5491 V |
| 5° | +0.4157 V | −0.5232 V |
| 20° | +0.5889 V | −0.4479 V |

- 두 열 모두 **각자 세션의 중립**을 기준으로 하므로 단순한 고정 전압 오프셋 차이가 아닙니다.
- `S08`의 왼쪽 독립 점들은 긴 오른쪽 Yaw 스캔 뒤에 측정되었습니다. 중립 이후 왼쪽 1°는 176.944초, 5°는 536.407초, 27°는 2516.960초 뒤이며, 첫 오른쪽 분기는 0~86.985초 구간입니다. 이 시간 차이 때문에 인과 방향이나 히스테리시스를 깨끗하게 추정할 수 없습니다.

`S06`과 `S08`에 공통인 Pitch 0° 좌우 동일 Yaw 명령 21개에 대한 같은 명령 평균의 절대 차이:

| 채널 | 중앙값 | 최대 |
|---|---:|---:|
| A1_C0 / DR | 0.3222 V | 0.5601 V |
| A1_C1 / UR | 0.2317 V | 0.4057 V |
| A1_C2 / DL | 0.0487 V | 0.2578 V |
| A1_C3 / UL | 0.1117 V | 0.4956 V |

이 비교에서는 양쪽 구동기가 모두 움직였으므로, 세션 간 변동을 보여 줄 뿐 각 구동기의 독립 이득을 나타내지는 않습니다.

### 9.2 규칙 기반 제어에 주는 결론

- 닫힘 방향이 확인되었으므로 **위치 피드포워드**를 씁니다. 차량 횡가속도를 필터링하고, 몸이 밀리는 쪽 볼스터를 고른 뒤, 정규화 요구량으로 Yaw 상한을 비례 배분합니다.
- 압력 근거로는 압력 목표 역산, PI 압력 추종, "가속도를 상쇄한다"거나 "흔들림을 줄인다"는 주장을 정당화할 수 없습니다.
- 네 A1 채널 감시 구성에서 p95 보간으로 얻은 초기 각도 추정(왼쪽 약 0.497°, 오른쪽 약 0.300°)은 후보값이며 안전 한계나 압력 20% 변화의 근거가 아닙니다. 런타임 제어기는 이 값을 각도 상한으로 쓰지 않고 설정한 Yaw 상한(20°)을 씁니다. → [fallback 검증 결과 §4](../VALIDATION.md#4-좌우-yaw-상한-20)
- 새 중립 기준선, 채널별 증가량·국부 집중 감시, 접촉 변화 감시, 변화율 제한, 명령 중립을 거친 방향 전환, 입력 지연 시 정지, fault 고정은 위치 피드포워드 정책의 필수 요소입니다.
- 부호 있는 압력 응답 검증은 이 정책에서는 참고 사항이지만, 압력 목표를 추종하는 제어기를 만든다면 **선행 조건**이 됩니다.

### 9.3 후속 측정 계획 (제안, 문서로만 존재)

이 노트만으로 1° 또는 2°로 범위를 자동 확장하지 않습니다. 이미 확인한 범위 안에서 시작해 실제 방향을 확인하고, 운용자가 명시적으로 결정할 때만 늘립니다.

| 항목 | 제안 |
|---|---|
| 계획 CSV 열 | `trial_id,block_id,condition,left_yaw_deg,left_pitch_deg,right_yaw_deg,right_pitch_deg,settle_s,dwell_s,operator_gate` |
| 시행 구성 | 단독 목표 직전·직후에 중립 `(0,0,0,0)`. 반대쪽 Yaw와 양쪽 Pitch는 0 |
| 조건 | 왼쪽 소각도 1개, 오른쪽 소각도 1개 (승인 시 1°, 2° 추가) |
| 반복 | 조건별 최소 5회, 기록한 시드로 순서 무작위화, 좌우 순서 균형 |
| 중단 시행 | 삭제하지 않고 기록 |
| 기록 항목 | 원시 압력, 명령·ACK·상태·PWM, 시계, 설정, 운용자 이벤트 |
| 시간 | 0.5초 안정화·2초 측정은 출발점일 뿐. 실제 구간 경계를 기록하고 접촉이 계속 변하면 측정 구간을 늘림 |
| 분석 순서 | 인접 전후 중립과 비교 → 부호 일관성, 반복 산포, 국부 집중, 중립 복귀 드리프트 확인 → 국소 응답 적합 → 바깥/안쪽 반복 쌍으로 히스테리시스 확인 |

위 점검이 해결되지 않으면 역압력 법칙을 적합하지 않습니다. 이 계획은 식별 제안이며 자동 실행 가능한 모터 일정이 아니고, 어떤 계획이나 명령도 업로드되지 않았습니다.

### 9.4 매핑 분석 재현

보존된 압력 전용 측정점 표에서 매핑 분석을 다시 만듭니다.

```powershell
# 4_Seat_Actuation 폴더에서
python -m fallback.build_mapped_analysis --point-table <data dir>\bench_pose_v1\pressure_command_points.csv --output fallback\profiles\mapped_analysis.json
```

빌더는 압력·모터 전용 CSV 스키마를 검증하고 프로파일·파생 표·빌더 소스의 해시를 남깁니다. 직렬 포트, 소켓, 카메라, 영상·자세 표는 열지 않습니다.

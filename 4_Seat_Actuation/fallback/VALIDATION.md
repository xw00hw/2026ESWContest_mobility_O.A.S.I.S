## 3. 펌웨어 ELF 에뮬레이션

`stm32/scripts/test_fallback_elf.py`가 실제로 생성된 ARM 코드를 Unicorn 에뮬레이터에서 실행합니다.

| 시험 종류 | 실행 모델 |
|---|---|
| 레지스터·통신 | Cortex-M7 모델 |
| 수학·연속 추종 | double-precision 명령 제약 때문에 ARM_MAX 모델 + PWM 경계 stub |

21개 PASS는 실시간 튜닝·CAD 한계 시험이 추가되기 전 스크립트 기준의 기록입니다. 현재 스크립트(39개)의 시험 항목은 [펌웨어 계약 §6](../stm32/FALLBACK_PROTOCOL.md#6-검증)에 정리했습니다.

실제 파형, 축 위치, 토크, 하중, 최악 지연을 검증한 결과는 아닙니다. 구성과 한계: [펌웨어 계약](../stm32/FALLBACK_PROTOCOL.md)

## 4. 좌우 Yaw 상한 20°

### 4.1 설정

| 항목 | 값 |
|---|---|
| 좌우 구조물 Yaw 상한 | 각각 **20°** (`max_yaw_deg`, 20° 초과 설정은 거부) |
| Pitch | 0° |
| 목표 변화율 | 최대 2 °/s (20 ms당 40 mdeg) |
| 최대 요구량 기준 횡가속도 | 0.30 g (`full_scale_ay_mps2` = 2.941995 m/s²) |
| 각도 산출 | 요구량 × 20° (요구량 0.5 → 10°, 1.0 → 20°) |
| 압력 감시 · 오류 시 OFF | 유지 |

벤치 프로파일의 압력 p95에서 역산한 정적 각도 상한(왼쪽 약 0.497°, 오른쪽 약 0.300°)은 각도 제한에 쓰지 않습니다. 프로파일은 채널별 압력 증가 한계(`pressure_fraction` = 0.20)에만 사용하며, 각도는 설정한 상한 안에서 위치 피드포워드로만 정합니다. 근거: [벤치 프로파일 노트](profiles/bench_profile_NOTES.md)

### 4.2 검증

| 검사 | 결과 |
|---|---|
| 매핑 프로파일 적용 | 좌우 상한 20°, 요구량 0.5 → 10° · 1.0 → 20° |
| 합성 압력 제어 루프 | 좌우 각각 20° 도달, Pitch 0°, 20 ms당 목표 변화 40 mdeg 이하, 방향 전환 전 중립 확인 |
| 20°에서 압력 급증·지속 초과 주입 | OFF 고정, heartbeat 중단 |
| 가짜 장치 통합 | 양방향 `FB_SET` 20000 mdeg, 종료 후 OFF 상태 수신 |
| 주행 기록 재생 (13,223행) | 양쪽 후보 목표 최대 20° |

- 펌웨어의 고정 하드 한계(구조물 yaw 0~27°, pitch ±8°)는 그대로입니다. Yaw 20°는 **호스트 쪽 운용 범위**이며, 운용 명령은 yaw 0~20°, pitch 0°입니다.
- 압력 감시가 발동하면 20°에 도달하기 전에 중립으로 돌아가거나 OFF될 수 있습니다.

# STM32 제어·압력매트·Arducam GUI

`Open_Control_Station.cmd` 실행. 의존성이 없으면 `Setup_Control_Station.cmd`부터 실행합니다.
현재 PC에는 필요한 패키지가 설치되어 있습니다.

1. 영상만 확인할 때는 압력 데이터 선택을 해제하고 Arducam을 열어 **기록 시작**을 누릅니다.
2. STM32는 아래 통합 펌웨어를 올린 후 포트를 선택해 연결합니다.
3. **구동 활성화** 후 왼쪽·오른쪽 구조물 Yaw·Pitch를 각각 조절합니다.
   왼쪽=D4·D6, 오른쪽=D3·D5입니다. 각 패널의 **영점**은 해당 쪽만 (0°,0°)로 이동합니다.
   **양쪽 영점**은 두 쪽 모두 이동하고 **Esc**는 현재 PWM을 유지하며 전체 구동을 비활성화합니다.
4. 아래 MUX 배선에서 **압력 측정 시작**을 누르면 12채널을 표시합니다.
5. 압력·영상을 선택해 **기록 시작**. 종료 시 CSV·영상·메타데이터를 닫고 구동을 정지합니다.

## 양쪽 Yaw AUTO 784

**양쪽 Yaw AUTO 784**는 왼쪽 Yaw 0~27° × 오른쪽 Yaw 0~27°의 1° 간격 **784개 조합**을 모두 기록합니다.
양쪽 Pitch는 0°입니다. 한 행에서 오른쪽을 왕복하고 왼쪽을 1°씩 증가시켜 인접 목표는 한쪽 Yaw만 1° 바뀝니다.
왼쪽/오른쪽 대상 선택과 관계없이 이 버튼은 두 쪽을 제어합니다.

압력 데이터·영상은 기본으로 선택되어 있습니다. 사용할 카메라(내장캠은 **Integrated Camera**)를 고르고 버튼을 누르면
STM32 연결·압력 측정·선택 카메라를 준비하고, 유효한 수신을 확인한 후 함께 기록하며 순회를 시작합니다.
준비 중에는 ARM을 보내지 않습니다. 준비 시간 초과/오류·Esc·AUTO 중지는 구동을 정지합니다.
완료하면 양쪽 (0°,0°)로 돌아온 후 HOLD를 확인하고 CSV·영상·자세별 통계를 저장합니다.
안정 0.5초·측정 2초 기본값에서 약 40분 예상입니다. 부팅 시 자동 실행되지는 않습니다.

기록에는 좌우 목표/보고 Yaw·Pitch, 각 크랭크 각도, 예상/보고 PWM, ACK·도달·측정 구간과
압력·영상 프레임이 들어갑니다. `auto_results.csv` 784행, `auto_pressure_summary.csv` 9,408행입니다.

## Yaw·Pitch AUTO

**AUTO 357**은 기존 Yaw·Pitch 조합 모드입니다. 선택한 압력·영상 소스를 자동 준비합니다.
대상은 **왼쪽 / 오른쪽 / 양쪽 동시** 중 선택합니다. 단일 쪽 AUTO는 반대쪽을 시작 시 명령 자세에 유지하고,
완료 시 선택한 쪽만 영점으로 돌아옵니다. 양쪽 동시는 좌우에 같은 Yaw/Pitch를 전송합니다.
Yaw **0~20°**, Pitch **−8~8°**의 **1° 간격 357개 조합**을 빠짐없이 한 번씩 순회합니다.
인접 목표의 변화는 1°이며, 수동 조작은 AUTO 종료까지 잠깁니다.

각 자세는 `전송 → 일치하는 ACK → STM32 명령 도달 → 0.5초 안정 → 2초 측정` 순서입니다.
완료하면 (0°,0°)로 복귀하고 HOLD 응답을 받은 뒤 기록을 종료합니다.
**AUTO 중지 / Esc / 기록 종료**는 즉시 중단하며 완료·중단·미시도 조합을 구분해 보존합니다.
통신/센서 오류나 다른 명령이 들어오면 중단합니다.

안정/측정 시간은 `station_config.json`의 `auto_scan.settle_s`, `dwell_s`에서 바꿀 수 있습니다.
구동 속도와 PWM 제한은 기존 STM32 제한을 그대로 따릅니다.
압력/영상을 선택하지 않아도 AUTO의 제어·명령 로그는 저장합니다.
선택한 소스가 준비되지 않으면 시작하지 않습니다.

| 추가 파일 | 내용 |
|---|---|
| auto_plan.csv | 목표 조합, 좌우 Yaw/Pitch·θ1·θ2, 예상 PWM |
| auto_events.csv | 실제 전송·ACK·도달·구간 전환의 PC 시각 |
| auto_points.csv | 시도한 자세의 명령 ID·예상/보고 PWM·MCU 시각·측정 시작/끝·종료 상태 |
| auto_results.csv | 전체 계획 조합의 결과, 미시도 표시, 압력 유효 수·영상 프레임 번호 |
| auto_pressure_summary.csv | 자세×12채널. 샘플 수·ADC 오류·평균·모집단 표준편차·최소·최대 |
| auto_summary.json | 전체 완료 수·중단 상태·통계 정의 |

통계는 **`dwell_start_ns ≤ 수신 시각 < dwell_end_ns`**에 해당하는 원본만 사용합니다.
이동·안정 구간은 평균에서 제외하며 원본 pressure.csv/motion.csv/영상은 보존합니다.
누락값은 0으로 대체하지 않습니다. 명목 100Hz 대비 실제 샘플 수도 저장합니다.
영상은 재생 프레임 시각으로 구간을 연결하고, 반복 프레임과 고유 원본 프레임 수를 구분합니다.
측정 종료 후 요약을 별도 스레드에서 생성하며 `AUTO_SUMMARY_INCOMPLETE`가 사라지면 정리가 끝난 것입니다.
도달 확인은 **STM32의 명령 상태** 기준이며 실제 축/구조물 위치를 측정하는 것은 아닙니다.

## 각도와 핀

수동 GUI 각도는 구조물의 Yaw **0~20°**, Pitch **−8~8°**입니다. Yaw 전용 AUTO는 Pitch=0°에서 27°까지 사용합니다.
원본 Viewer의 C4_R8 역기구학으로 중립 대비 로컬 크랭크 각도 θ1·θ2를 구합니다.
단순한 Yaw/Pitch 선형 혼합을 사용하지 않습니다.

| 출력 | 역할 | DS 명령 |
|---|---|---|
| D3 / PE13 | 오른쪽 상부 | −θ1,R |
| D4 / PE14 | 왼쪽 상부 | θ1,L |
| D5 / PE11 | 오른쪽 하부 | θ2,R |
| D6 / PE9 | 왼쪽 하부 | −θ2,L |

네 모터 모두 **DS5180 270°**, `PWM = 핀별 영점 + 부호 적용 각도 × 2000/270` µs입니다.
부팅/GUI (0°,0°) 영점은 D3/D4/D5/D6 = **1800/1200/1200/1800µs**입니다.
1200µs 크랭크 기준을 좌우 반전한 값이며, 모터 스펙상 중앙 1500µs와는 구분합니다.
자동 왕복 없음. PWM 50Hz, 명령 갱신 20ms, 모터 속도 제한 15°/s를 유지합니다.
CAD 전역 `rx`와 로컬 `φ`는 다릅니다. 여기서 θ는 **로컬 φ의 중립 대비 각도**입니다.
계산된 자세와 실제 기구 자세가 같다는 실측 검증은 아직 하지 않았습니다.
`station_config.json`의 매핑은 현재 펌웨어를 기록한 값이며, 파일 값만 바꿔서는 모터 설정이 바뀌지 않습니다.

예: 왼쪽만 Yaw=20°, Pitch=8°이고 오른쪽이 영점이면 D3/D4/D5/D6=1800/1406/1200/1287µs입니다.
좌우에 같은 자세를 주면 D3·D4 및 D5·D6가 각각 1500µs를 중심으로 대칭입니다.
확장 범위는 원본 R8 형상으로 계산했습니다. 원본 Viewer 범위(0~15°, ±8°)와 참조 파일은 그대로 보존합니다.
0.25° 간격 6,561개 자세에서 도달 가능·PWM 500~2500µs 이내를 검증했으며,
실물 간섭·확장 끝점·하중·새 영점과 실제 구조물 각도의 일치는 아직 측정하지 않았습니다.

## MUX 배선 변경

| 신호 | 새 핀 | MCU 핀 |
|---|---|---|
| S0 | D8 | PF3 |
| S1 | D9 | PD15 |
| S2 | D10 | PD14 |
| S3 | D11 | PB5 (기본 솔더브리지) |
| EN (active low) | D12 | PA6 |
| SIG 0/1/2 | A0/A1/A2 | PA3/PC0/PC3_C |

세 MUX의 주소선은 공통입니다. 원래 D3~D6 주소선 배선을 그대로 두면 서보 PWM과 충돌합니다.
2026-10-24 사용자가 위 배선 연결을 확인했고, EN=D12 펌웨어 업로드 및 12채널 수신을 검증했습니다.
각 MUX의 C0~C3를 읽어 총 12입력입니다. 기본 기록 소스는 압력과 영상 모두 선택됩니다.
압력은 ADC raw와 추정 전압(V)이며 힘·압력 보정값은 아닙니다.

## 펌웨어·검증

통합 펌웨어와 업로드 방법: [firmware/bolster_h723](../stm32/README.md).
기존 압력시트 펌웨어·시각화는 변경하지 않았습니다. 기존 v9 파서만 재사용합니다.

```powershell
python -m unittest discover -s tests -v
```

Native C 기구학까지 시험하려면 먼저 `../stm32/scripts/build_native_math.cmd` 실행 후:

```powershell
$env:OASIS_JOINT_MATH_DLL='C:\Temp\seat_control_data_acquisition\joint_math.dll'
python -m unittest discover -s tests -v
```

원본 JavaScript 기준값, Python/C 기구학 일치, 속도 제한, UART 모의 연결,
영상 시간축·CSV 저장을 검사합니다. [검증 기록](VALIDATION.md)에 실물 검증 범위를 구분했습니다.

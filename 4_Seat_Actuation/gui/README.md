# 볼스터 측정 스테이션 (gui)

> 볼스터를 수동으로 움직이거나 **각도 조합을 자동으로 순회**하면서, 각 자세의 압력 12채널과 카메라 영상을 함께 기록하는 Windows 프로그램입니다.
> 여기서 얻은 "각도 → 압력·자세" 관계가 압력 감시 기준과 학습 시뮬레이터의 접촉 모델을 정하는 근거가 되었습니다.

---

## 주요 기능

| 기능 | 내용 |
|---|---|
| 수동 제어 | 왼쪽·오른쪽 구조물 Yaw(0 ~ 20°)·Pitch(±8°)를 각각 조절, 한쪽 또는 양쪽 영점 복귀 |
| 압력 표시 | MUX 12채널 실시간 표시 |
| 동시 기록 | 압력·명령/상태·영상을 같은 PC 시계로 기록 |
| **AUTO 357** | Yaw 0 ~ 20° × Pitch −8 ~ 8°, 1° 간격 357개 조합을 한 번씩 순회 (왼쪽 / 오른쪽 / 양쪽 동시) |
| **양쪽 Yaw AUTO 784** | 왼쪽 Yaw 0 ~ 27° × 오른쪽 Yaw 0 ~ 27°, Pitch 0°, 784개 조합 (약 40분) |

### AUTO 순회 방식

```text
각 자세:  명령 전송 → 일치하는 ACK → STM32 명령 도달 → 0.5 s 안정 → 2 s 측정
완료 후:  양쪽 (0°, 0°) 복귀 → HOLD 확인 → 자세별 통계 저장
```

- 인접 목표는 한 축만 1°씩 바뀌도록 순서를 짜서 기구에 무리를 주지 않습니다.
- 통계는 측정 구간(`dwell_start_ns ≤ 시각 < dwell_end_ns`)의 원본만 사용하고, 이동·안정 구간은 제외합니다.
- `AUTO 중지` / `Esc` / 통신·센서 오류 시 즉시 중단하며, 완료·중단·미시도 조합을 구분해 남깁니다.

## 각도와 서보

구조물 Yaw/Pitch에서 역기구학(C4_R8)으로 크랭크 각도 θ1·θ2를 구하고, 서보별 부호를 적용합니다.

| 출력 | 역할 | 서보 명령 |
|---|---|---|
| D3 / PE13 | 오른쪽 상부 | −θ1,R |
| D4 / PE14 | 왼쪽 상부 | θ1,L |
| D5 / PE11 | 오른쪽 하부 | θ2,R |
| D6 / PE9 | 왼쪽 하부 | −θ2,L |

`PWM = 핀별 영점 + 부호 적용 각도 × 2000 / 270` µs (DS5180 270°). 이 프로그램이 쓰는 측정용 펌웨어(OASIS_CONTROL v6)의 영점은 D3/D4/D5/D6 = 1800/1200/1200/1800 µs입니다.
0.25° 간격 6,561개 자세에서 모두 도달 가능하고 PWM 500 ~ 2500 µs 안에 있음을 확인했습니다.

## 실행 방법

```powershell
Setup_Control_Station.cmd        # 처음 한 번: 의존성 설치 (Python 3.10+, Tk 포함)
Open_Control_Station.cmd         # 실행
```

1. 측정용 펌웨어를 올린 보드의 COM 포트에 연결합니다.
2. 카메라를 고르고 압력·영상 기록 여부를 정합니다.
3. **구동 활성화** 후 수동 조절하거나 AUTO를 시작합니다. **Esc**는 현재 PWM을 유지한 채 구동을 비활성화합니다.

## 기록 파일

`sessions/<시각_UUID>/` 아래에 저장합니다.

| 파일 | 내용 |
|---|---|
| `pressure.csv` | 12채널 원시값·상태·추정 전압, MCU ms, PC 시각 |
| `motion.csv` | 좌·우 명령 각도·목표 각도·PWM·구동 상태 |
| `commands.csv`, `raw_serial.jsonl` | 전송 명령과 응답, 원시 수신 바이트 |
| `camera.avi`, `frame_timestamps.csv` | MJPG 영상, 프레임별 실제 캡처 시각과 반복 여부 |
| `auto_plan.csv`, `auto_points.csv`, `auto_results.csv` | AUTO 계획, 시도한 자세, 전체 결과 |
| `auto_pressure_summary.csv`, `auto_summary.json` | 자세 × 12채널 통계, 전체 요약 |

- 모든 기록에 PC `perf_counter_ns`와 UTC 시각을 함께 남깁니다.
- 영상은 30 fps 시간축에 맞추고, 카메라가 느리면 이전 프레임을 반복하되 반복 여부를 따로 기록합니다.
- 누락값은 0으로 채우지 않습니다. 도달 확인은 STM32 명령 상태 기준이며 실제 축 위치 측정은 아닙니다.

기록된 세션을 압력·자세 표로 정리하는 방법은 [`processing/`](processing/README.md)에 있습니다.

## 검증

```powershell
python -m unittest discover -s tests -v
```

원본 JavaScript 기구학과의 일치, Python/C 기구학 일치, 속도 제한, UART 모의 연결, 영상 시간축, CSV 저장을 검사합니다.
C 기구학까지 시험하려면 먼저 `../stm32/scripts/build_native_math.cmd`로 DLL을 빌드하고 `OASIS_JOINT_MATH_DLL`에 경로를 지정합니다.

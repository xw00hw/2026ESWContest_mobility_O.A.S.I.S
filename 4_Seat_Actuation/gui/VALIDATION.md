# 측정 스테이션 검증 결과

> 측정 스테이션으로 수행한 **실측 3세션(`S06`~`S08`)의 데이터 무결성·자세 추정 결과**와, 펌웨어 통신 버전(v3~v6)별 시험·실물 검증 결과입니다.
> 모의 시험과 실물 기록을 구분해 적고, 측정하지 않은 항목은 마지막 절에 모았습니다.

---

## 1. 실측 세션

| 세션 | 시험 | 측정점 | 10 Hz 자세 샘플 | 착석자 gate 유효율 |
|---|---|---:|---:|---:|
| `S06` | 양쪽 Yaw/Pitch | 357 | 11,590 | 99.80% |
| `S07` | 왼쪽 Yaw/Pitch | 357 | 11,509 | 99.63% |
| `S08` | 좌우 독립 Yaw 28 × 28 | 784 | 25,304 | 99.79% |

### 1.1 데이터 무결성

| 항목 | 결과 |
|---|---|
| 세션 종료 | 3세션 모두 정상 종료, 원본 오류 0 |
| 규모 | 측정 구간 1,498개, 압력 값 5,834,640개, 원본 영상 145,207프레임 |
| 명령 대조 | 계획 각도 조합 · 보고 명령각 · PWM 대조 → 누락·중복·불일치 0 |
| 압력 | 패킷 누락 0, ADC 오류 0 |
| 측정 구간 | 각 2초. 압력 평균 재집계와 원래 요약의 최대 차이 < 1e−8 V |

### 1.2 자세 추정

| 항목 | 내용 |
|---|---|
| 모델 | RTMPose-m / COCO17 |
| 입력 영역 | 영상 중앙 `(300,120)–(920,720)`, 좌표는 원본 영상 픽셀 |
| 샘플링 | 원본 30 fps 인덱스와 반복 여부를 유지하고 매 세 번째 표시 프레임 사용 → 10 Hz 자세 48,403개 |
| 실제 추론 | 중복 캡처 제거 후 48,400개, 측정 구간당 실제 자세 캡처 19~21개 |
| gate 유효율 | 모델·위치 조건 통과 비율. 정답 대비 정확도가 아님 |

- **시간 정렬:** QPC 시계로 압력·상태·자세를 정렬합니다. 자세는 최근접 ±100 ms, 상태는 과거 최대 500 ms로 제한하고 실제 age를 검사하며, 범위 밖 값은 결측으로 둡니다.
- **카메라 조정 구간:** `S07` 영상의 239~280초 카메라 조정·손 뻗기 구간을 보수적으로 표시하고, 구간 전·중·후 camera epoch를 구분합니다. 75~86번 측정점 12개의 분석용 자세 평균은 결측이며, 원시 좌표·score·압력은 유지합니다.
- **관측 불가 관절:** 무릎·발목은 화면 밖이므로 항상 invalid입니다. 2D 자세를 3D 인체 각도로 해석하지 않습니다.

### 1.3 출력 검증

- 균등 간격 시점, 관절 유효성이 낮은 샘플, 카메라 조정 샘플을 원본 영상과 육안 대조했습니다.
- 출력 MP4 3개를 전체 디코딩해 각 11,590 / 11,509 / 25,304프레임이 일치하고, 전체 관절 유효 mask 검사가 통과했습니다.
- 처리 코드 시험 5개 통과: 시각 경계, crop 좌표, 관측 불가 관절, feature 부호 등.
- 재현 코드: [processing](processing/README.md). 원본은 변경하지 않으며 입력 SHA-256·코드·모델·환경을 기록합니다. 데이터·영상·가중치는 로컬 `data/processed/bench_pose_v1/`에 두며 저장소에 포함하지 않습니다.

## 2. 좌우 독립 Yaw AUTO 784

| 항목 | 결과 |
|---|---|
| 순회 계획 | 좌우 각각 0~27°, 28 × 28 = 784개 목표 중복·누락 없음, 양쪽 Pitch 0°, 인접 목표 1° 변화 |
| 모의 순회 | 784개 전체 명령 · ACK · 도달 · 측정 · 영점 복귀 · 요약 저장 |
| 시험 | 38개 통과 — 준비 중 압력·카메라 대기, ARM 금지, 취소, 27°에서 Native C / Python 일치, PWM slew |
| 펌웨어 | ST-LINK 컴파일·업로드·Flash 검증. Yaw 한계 27000 mdeg, Pitch 한계 8000 mdeg |
| 기록 경로 시험 | 노트북 내장 카메라 + 압력 자동 준비·동시 기록 약 4.4초: 압력 5,217개, 상태 22개, 영상 133프레임(원본 111 · 반복 22), 오류·패킷 누락·파서 오류 0 |

기록 경로 시험은 `_start_scan`을 기록 전용으로 대체해 ARM·SET 없이 수행했습니다. 이 시험 세션의 AUTO 상태는 `not_run`, 784개 목표는 모두 `not_attempted`로 남습니다. 실물 784점 순회 결과는 1절의 `S08`입니다.

## 3. 통신 버전별 검증

GUI는 HELLO 버전으로 펌웨어를 구분하며, v4부터 매핑이 다른 이전 버전과의 혼용을 거부합니다.

| 버전 | 핀 · 영점 | 운용 범위 |
|---|---|---|
| **v6** (현재) | 왼쪽 D4·D6, 오른쪽 D3·D5 독립. 영점 D3/D4/D5/D6 = 1800 / 1200 / 1200 / 1800 µs | 측정 스테이션 기본 |
| v5 | 좌우 반전 유지, 1200 µs 기준 영점 1800 / 1200 / 1200 / 1800 µs | Yaw 0~20°, Pitch ±10°, AUTO 441개 |
| v4 | D4 = θ1, D6 = −θ2, D3 = −θ1, D5 = θ2 (좌우 장착 반전), 모두 1500 µs 기준 | Yaw 0~15°, Pitch ±8° |
| v3 | `D3=D4=θ1`, `D5=D6=−θ2`, 중립 1500 µs. 세트 D3+D5 / D4+D6 | Yaw 0~15°, Pitch ±8°, AUTO 272개 |

θ1·θ2는 구조물 Yaw·Pitch의 C4_R8 역기구학 결과에서 중립을 뺀 로컬 크랭크 각도입니다.

### 3.1 v6 — 좌우 독립 제어

- GUI 좌우 4개 입력과 쪽별 영점, 원자적 4각도 SET/ACK, `STATE`·`motion.csv`의 좌우 현재·목표 분리.
- **35개 시험 통과:** C/Python 독립 PWM 일치, 한쪽 이동 시 반대쪽 PWM 고정, PWM slew 제한, 수동 입력·한쪽 영점, 좌우 개별 AUTO 441개 전체 순회·선택한 쪽만 복귀. 원본 JS 기준·확장 범위·압력/영상 시간창 시험 유지. 독립 이동은 모의·Native C 시험입니다.
- **실물:** ST-LINK 업로드·Flash 검증. HELLO v6 / `joints=2`, 좌우 0°/0°, D3/D4/D5/D6 = 1800/1200/1200/1800 µs, armed=0, moving=0 확인.
- **기록 `S05`:** 약 7초, 압력 12채널 각각 약 100 Hz, ADC 오류·파서 오류·패킷 누락 0. 원시 UART/CSV와 펌웨어 SHA256을 세션에 보존.
- GUI(1220 × 845)에서 좌우 Spinbox 4개 표시, 압력 수신, Arducam 미리보기 확인.

### 3.2 v5 — 1200 µs 기준 영점, 범위 확장

- 원본 R8 역기구학·형상은 그대로 두고 운용 범위와 핀별 보정 영점만 변경했습니다. 원본 참조 파일은 이전 범위(0~15°, ±8°)입니다.
- 모터 부호, 15 °/s 속도, PWM 500~2500 µs 제한 유지.
- 0.25° 간격 6,561개 자세에서 C/Python PWM 일치·도달 가능 확인. 핀별 PWM 범위: D3 = 1214~1985, D4 = 1015~1786, D5 = 1015~1786, D6 = 1214~1985 µs.
- 확장 끝점 간 S커브 속도·PWM 변화 제한, 모의 AUTO 441개 전체 순회 포함 **30개 시험 통과**.
- **실물:** 빌드·업로드·Flash 검증, HELLO v5, 새 영점, armed=0, moving=0 확인.
- **기록 `S04`:** 약 7초, 12채널 총 8,430개 값, 각 100 Hz, ADC 오류·파서 오류·패킷 누락 0. 펌웨어 SHA256과 원시 UART/CSV 보존.

### 3.3 v4 — 좌우 장착 반전

- Python/C PWM 계산, GUI 표시, 기록 설정, AUTO 계획이 같은 매핑을 사용합니다.
- 구버전(v3) 거부 시험 포함 **30개 시험 통과**. C/Python 1,023개 자세 PWM 일치, S커브 속도·PWM 변화 제한 통과.
- 예: Yaw 15°, Pitch 0°의 예상 PWM은 D3/D4/D5/D6 = 1251/1749/1749/1251 µs.
- **실물:** 업로드·Flash 검증, v4 응답, 1500 µs, armed=0, moving=0 확인.
- **기록 `S03`:** 12채널 모두 100 Hz, ADC/파서 오류·패킷 누락 0. ARM·SET·AUTO는 보내지 않았습니다.

### 3.5 v3 — AUTO 순회와 기본 통합 GUI

**AUTO (전체 30개 시험 통과: 기존 20개 + AUTO/GUI 10개)**

- 실제 장치 없는 모의 UART·시계로 272개 조합 전체 순회·명령 도달·측정·중립 복귀 검증. 조합 중복·누락 없음, 인접 목표 1° 변화.
- ACK가 없으면 진행 금지. 다른 명령·도중 이동·비활성화·stale 감지 시 중단.
- 측정 시작 경계 포함·종료 경계 제외, 이동 중 데이터 제외, ADC 오류 별도 집계.
- 자세별 영상 프레임 번호와 원본·반복 구분, 중단·미시도 기록.
- Tk AUTO 버튼의 시작·취소·수동 조작 잠금, 파일 저장 시험 통과.

**기본 통합 GUI**

- STM32 ARM 펌웨어 빌드 통과(기존 newlib syscall stub 경고만 존재).
- 오프라인 20개 시험 통과: 원본 JS 기준 25개 자세, Python/C 1,023개 자세 일치, Native C S커브 모터 속도와 독립 PWM 변화 제한.
- GUI 생성, 장치 검색, 창 안 기록 버튼 표시 확인.
- **Arducam OV9281 실물:** GUI 기록 버튼으로 1280 × 800 영상 약 4초 기록·종료·재열기. 최종 AVI 123프레임 / 30 fps(4.1초), 원본 캡처 44 · 반복 79, 저장 오류 없음.
- 원본 캡처 속도를 30 fps로 주장하지 않습니다. `frame_timestamps.csv`에 원본 시각과 반복 여부를 기록합니다.
- 압력 UART 파서의 uint32 wrap, 오류·빈 raw 처리 시험.

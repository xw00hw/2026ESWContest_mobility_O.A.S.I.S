## 동작 검증 내용

1. 압력 없는 실제 제어기+모의 UART/수집기 경로가 구동한다. 잔여 압력 바이트가 없거나 잘못되어도 동일한 차량 입력에는 동일한 모터 명령을 낸다. FSR 스캔 시작·압력 heartbeat·압력 기준선은 없다.
2. 좌우 같은 크기 횡가속도에 대칭 Yaw·Pitch가 나온다. 40초 모의 런타임에서 우측 Yaw 20° 도달 후 중립 경유를 확인하고 좌측 Yaw 20°로 전환했다. 예상 sagittal 각도를 측면 패드 Pitch로 오인하지 않는다.
3. 임의 방향 전환에서도 동시 양쪽 폐쇄가 없고, 비선형 IK·결합 각도·합성 PWM 속도 제한을 유지한다. 밀리도 양자화와 실제 펌웨어의 2 µs/프레임 제한을 구분한다.
4. 이상 시각·순서·stream 전환·stale·ACK 불일치·MCU reset·초기 비중립·OFF 응답 누락을 검출한다. 하나의 수신 배치에서 나쁜 행 뒤 좋은 행이 들어와도 오류를 숨기지 않는다.
5. 확인되지 않은 후보 설정은 UART/UDP 개방 전에 거부한다. 오프라인 명령은 장치를 열지 않는다.

## 기록 재생 결과

입력 상태: 정상 10,957행, 정지 2,233행, host gap 2행, 횡가속도 이상 21행, 종가속도 이상 7행, 미분 무효 3행. 연속 제어 호스트 간격 조건에서 추가로 3회의 모델 세션 중단을 표시했다.

후보 설정(각축 2°/s, counter_lean, 문헌 기준 체격)에서 최대 명령은 LY 10.115° / LP 절댓값 1.993° / RY 11.403° / RP 절댓값 1.750°였다. 최대 예상 미보조 몸통 Roll은 18.036°였다. 이는 기록된 입력에 대한 모델 값과 제한 후 명령이며, 실측 몸통 각도·모터 위치·압력이 아니다. 2°/s 제한과 중립 경유 때문에 빠른 코너링에서 요청 최대각에 도달하지 않을 수 있다.

Replay는 이상 후 구간별로 새 가상 세션을 만들어 총 11개 분석 구간을 계산했다. live의 오류 후 자동 ARM은 없다. 보드 명령 상태는 즉시 따라온다고 가정했으며 실제 서보 부하 응답이나 압력은 모델링하지 않았다. 전송한 하드웨어 명령은 **0개**다.

## 민감도와 미검증 범위

동일 0.30g에 모델 Roll 고유진동수를 0.6/1.2/2.0Hz로 바꾸면 정적 예상 각도는 약 21.99/5.50/1.98°가 된다(첫 값은 내부 20° 한계에서 제한). 이 후보들은 참가자에 대한 신뢰구간이 아니라 미식별 변수의 영향을 확인하기 위한 설계 경우다. 주파수·감쇠를 확인하지 않고 개인별 정확도나 횡가속도 억제 효과를 주장하지 않는다.

기존 펌웨어 소스·바이너리에는 이번 작업으로 변경이 없고 재업로드하지 않았다. 실제 장착축·나사 체결·영점·응답 지연·부하·착좌감과 A/C 공정 비교 조건은 후속 실험에서 확인한다.

# 백업 제어기 · 데스크톱 앱 검증

> 현재 배포 기준(V7)의 오프라인 시험, 기록 재생, 펌웨어 에뮬레이션, CAD 검사 결과와 아직 검증하지 않은 범위를 정리합니다.
> 모든 시험은 가짜 UART·루프백 소켓·가상 시계·기록 재생·Cortex-M7 에뮬레이터에서 수행했으며, **V7로 실제 모터를 구동한 결과는 포함하지 않습니다.**

---

## 3. 호스트 시험 범위

호스트 시험은 가짜 UART, 루프백 수신기, 가상 단조 시계를 주입합니다. 일부 시험은 생체역학 모델과 무관하게 오케스트레이션만 확인하고, 종단 간 시험은 실제 응답 계산과 명령 제한기를 사용합니다. 가짜 보드는 위치를 즉시 확인 응답하므로 **실제 서보·압력·몸통 움직임의 측정이 아닙니다.**

### 3.1 입력 검증 · 시작 · 종료

| 시험 내용 | 확인 결과 |
|---|---|
| 시각·순번·stream/세션 전환·200 ms 초과 지연·미분 무효 행 | 검출 후 OFF. 구동 전에는 시작 자격 확인을 처음부터 다시 함 |
| 한 수신 배치 안에서 나쁜 행 뒤에 좋은 행이 오는 경우 | 앞선 오류를 숨기지 않음 |
| ACK 불일치, MCU reset, 초기 비중립 상태, OFF 응답 누락 | 검출 후 종료 |
| 확인되지 않은 설정·장착 확인값 | UART/UDP 개방 **전에** 거부. 오프라인 명령은 장치를 열지 않음 |
| 보드 현재 명령 또는 목표가 Yaw·Pitch 결합 한계 초과 | OFF로 고정 |
| 수신 처리 중 수집기가 만든 새 차량 행 | 수신 뒤 시각을 다시 읽어 `future_timestamp`로 오인하지 않음 |
| 수신 도중 중지 요청 | 같은 반복에서 ARM·lease·SET을 보내지 않음 |
| 종료 | `FB_OFF`와 압력 `DISABLE`의 ACK를 각각 확인, 300 ms 안의 새 OFF STATE로만 종료 확인 |

### 3.2 제어 출력

- 좌우 같은 크기의 횡가속도에 대칭인 Yaw·Pitch가 나옵니다.
- 임의 방향 전환에서도 양쪽 볼스터가 동시에 닫히지 않고, 반대쪽으로 바뀔 때는 반드시 중립 명령을 거칩니다.
- 모든 목표가 CAD 엔벨로프(Yaw 22°, Yaw별 Pitch 상한) 안에 있고, 비선형 IK·결합 각도·PWM 변화율 제한을 유지합니다. 밀리도 양자화와 펌웨어의 2 µs/프레임 제한을 구분합니다.
- 큰 횡가속도는 Yaw 상한에 포화하며 제어를 멈추지 않습니다.
- `right_only` 설정에서는 없는 쪽(왼쪽)을 명령하거나 기다리지 않습니다.

### 3.3 압력과 제어의 분리

- 낮은·높은 압력, 손상되거나 누락된 압력 행, 잔여 스캐너 바이트가 있어도 **같은 차량 입력에는 같은 모터 명령**이 나옵니다. 압력은 `controller.tick`의 인자가 아닙니다.
- 압력 원시 행의 ADC·상태 코드·MCU tick·순번·호스트 시각과 완성된 12채널 스캔을 JSONL·CSV에 보존합니다. 파싱 오류·순번 누락·큐 드롭·미완성 스캔은 품질 이벤트로 기록합니다.
- 기록 쓰기와 fsync는 유한 큐를 가진 별도 스레드에서 수행합니다. 큐 초과·디스크 오류·종료 시간 초과를 감지하면 `INCOMPLETE`를 남기고, 오류 로그 기록이 다시 실패해도 모터 OFF 경로를 건너뛰지 않습니다.

### 3.4 데스크톱 자동 실행

| 시나리오 | 확인 결과 |
|---|---|
| 차량 수집기 소켓·파일 준비 전 | 보드 포트를 열지 않음 |
| USB 미연결 | 대기 후 연결되면 유효 차량 입력 2초·보드 OFF를 확인하고 한 번만 ARM |
| 게임 로딩 31초 대기(모의) | 시간 제한 없이 압력 스캔·독립 PING을 유지한 뒤 시작 |
| 중복 실행 | Windows 파일 잠금으로 두 번째 인스턴스 거절, 잠금 해제 후 재획득 |
| 사용자 중지·수집기 종료·제어 오류 | 공통 stop 경로로 전달, 창 닫기는 수집기 저장 완료를 기다림 |
| 오류·예외·통신 복구 후 | 자동 재ARM·재시작 없음 |
| 미저장 기록 | 저장/버리기를 고르기 전까지 자동 시작·재연결 차단 |
| 저장 | 같은 볼륨은 이름 변경, 다른 볼륨은 복사 후 해시 확인. 기존 대상은 덮어쓰지 않음 |
| 버전 업데이트 | 복사·구문·해시 검증 후에만 활성 버전 전환, 구동 중 교체 없음 |

### 3.5 충격 의심 판정

포화·고립된 단일 최댓값·지속되는 전방/측방 충격·극단 입력·정지 입력·중복/공백 처리·벡터 누적·재생 중 래치를 다루는 집중 시험 17개를 통과했습니다.

기존의 단일 표본 임계값(|a_y| > 12 m/s² 또는 |a_x| > 15 m/s²)은 비충돌로 확인된 기록 `S14`에서 한 표본(a_y 12.87 m/s², a_x +7.25 m/s², 합성 14.77 m/s², 13.5 ms 뒤 6.94 m/s²)만으로 세션을 종료시켰습니다. V7은 이를 **포화(정상 제어)**와 **충격 의심(모터만 OFF, 기록 유지)**으로 분리했고, 이 939행 기록과 합성 32.93 m/s²의 고립 최댓값이 있는 1,527행 라벨 없는 기록 모두 충격 이벤트 없이 재생됩니다.

> 합성한 양성 사례는 실제 충돌 검출 성능을 입증하지 않습니다. 판정 조건은 [RUNTIME.md](RUNTIME.md)를 참고합니다.

## 4. 펌웨어 ELF 에뮬레이션

`stm32/scripts/test_fallback_elf.py`는 실제로 빌드한 `fallback_control_h723.elf`를 Unicorn 에뮬레이터에서 실행합니다. Cortex-M7 모드로 제어·PWM·IWDG 레지스터 명령을 실행하고, 배정밀도 연산이 필요한 기구학·추종 시험은 하드웨어 경계만 대체한 `ARM_MAX` 모드로 실행합니다. 현재 스크립트는 39개 시험 케이스로 구성되며, 기록된 통과 결과는 270° 매핑 정정 이전 V2 펌웨어 기준 37개입니다.

| 범주 | 확인 내용 |
|---|---|
| CAD 가드 | 정수 Yaw 0~22,000 mdeg 전 구간의 ± 경계와 경계 바로 밖, CAD 위반 시 원자적 거부와 전체 출력 OFF |
| 기구학 | ELF의 크랭크 각도·좌우 대칭 펄스가 호스트와 일치, 270° 게인을 독립 계산한 기준 펄스와 대조 |
| 변화율 | 축별 각속도 제한과 PWM 2 µs / 20 ms 제한이 재목표 중에도 동시에 유지, 공백 후 따라잡기 없음 |
| 출력 안전 | 첫 프레임 0 후 전체 중립, OFF·레지스터 손상 시 모든 출력 LOW, MUX GPIO 비간섭 |
| watchdog · lease | 제어 반복이 끝났을 때만 IWDG 갱신, lease 만료 후 권한 복구 없음 |
| 튜닝 커밋 | 명시적·원자적 커밋, 새 순번 필요, 구동 중 BUSY 커밋은 설정·lease를 바꾸지 않음, 범위 밖 정수는 트랜잭션 전체 거부 |
| 프로토콜 | 세션 재사용 거부와 새 명시적 ARM, 잘못된 명령 ID·형식은 닫힌 상태로 실패 |

에뮬레이션은 물리적 타이밍, 부하, 출력축 위치를 증명하지 않습니다.

## 5. CAD 간섭 검사와 STM 튜닝 환경

- 실제 3D 모델(STEP)에서 중립 208개, 가동 그룹 간 간섭 51자세, 주요 부품 간격 437자세, 운동학 45,141자세를 검사했습니다. 최소 간격 0.714 mm, 최소 전달각 사인 0.781.
- 결과 프로파일(SHA256 `564128a1…c043eb36`)을 호스트와 펌웨어가 함께 사용하며, `CONTROL_HELLO`에서 해시가 다르면 시작하지 않습니다.
- STM32CubeIDE 프로젝트(`stm32/cubeide`)는 import를 확인했고, Live Expressions에 튜닝 변수 14개를 미리 등록했습니다. 소스와 미리 빌드한 ELF를 보는 용도이며 자동 빌드·업로드는 하지 않습니다.

## 6. 실제 주행 기록 재생

재생은 보드 명령 상태가 즉시 따라온다고 가정하며 실제 서보 부하 응답이나 압력은 모델링하지 않습니다. 이상 이후 구간은 오프라인 분석용으로 새 가상 세션을 만들지만, 실시간 실행에는 오류 후 자동 재ARM이 없습니다. 모든 재생에서 전송한 하드웨어 명령은 **0개**입니다.

### 6.1 입력 분류 (13,223행)

입력 SHA-256: `f8a56797a8e43d56a6453062da5d9d3bfaa4081c10a67a1cd3e421e12e5e082c`

| 입력 상태 | 행 수 |
|---|---:|
| 정상 | 10,957 |
| 정지 | 2,233 |
| 호스트 수신 공백 | 2 |
| 횡가속도 이상 | 21 |
| 종가속도 이상 | 7 |
| 미분 무효 | 3 |

연속 제어 호스트 간격 조건으로 정책 세션 중단 3회를 추가로 표시했고, 독립 분석 구간은 11개입니다.

### 6.2 CAD 한계 적용 설정 재생 (5,411행)

CAD 결합 한계를 적용한 설정으로 5,411행 기록을 재생해 통과했습니다. invalid·gap·outlier 행을 정상 입력과 구분해 처리했습니다.

## 7. 속도 설정 근거

0 → 0.30 g 계단 입력, 호스트 명령 40 ms 간격, 펌웨어 20 ms당 채널별 2 µs 제한을 가정하고 펌웨어 `Joint_LimitStep`의 Python 포팅으로 명령 갱신을 모사했습니다. 실행 중인 ELF나 실제 모터 측정이 아니며, 시간 원점은 시작 자격 확인 후 첫 차량 입력입니다. 기록 비교 구간은 유효 연속 구간 중 58.3249초·2,917행입니다.

| Yaw / Pitch 변화율 (°/s) | 0 → 20° 시간 (s) | 0 → 25° 시간 (s) | 기록 구간에서 PWM 제한 작동 비율 |
|---|---:|---:|---:|
| **2 / 2 (현재)** | **10.14** | **12.64** | **0.0%** |
| 4 / 2 | 5.16 | 6.56 | 1.3% |
| 4 / 3 | 5.14 | 6.54 | 3.0% |
| 5 / 3 | 4.20 | 5.58 | 36.7% |
| 6 / 4 | 3.90 | 5.28 | 69.7% |
| 10 / 6 | 3.90 | 5.28 | 70.1% |

5 °/s 이상에서는 PWM 변화율 제한에 자주 걸려 실제 속도가 더 빨라지지 않습니다. 현재는 가장 보수적인 2 / 2 °/s로 운용하며, 변화율 제한과 중립 경유 때문에 빠른 좌우 전환을 완전히 따라가지는 못합니다.

## 8. 역기구학 도달 범위 (R8)

| 검사 | 결과 |
|---|---|
| Yaw 0~20°, Pitch ±4° / ±8° 영역 0.1° 격자 | 16,281 / 32,361개 자세 IK 가능 |
| Yaw 0~27° 0.01° 간격 × Pitch 허용폭 5개 비율 | 13,505개 자세, 최대 역삼각함수 인수 `|q| = 0.939099` (특이 경계 1 미만) |
| 해당 자세의 실수 PWM 범위 | 1193.799 ~ 1806.201 µs |
| 기하학적 도달 경계 | 순수 Yaw 27° 도달 가능, Yaw 25°에서 Pitch 약 5.102°, Yaw 27°에서 약 2.795° |

이는 도달 가능성과 명령 범위의 수치 검사이며 패드 접촉점이나 부품 간격의 검증은 아닙니다. 실제 운용 범위는 이보다 좁은 **CAD 간섭 한계(Yaw 22°)**로 정합니다.

## 9. 대체된 후보 설정

현재 설정(V7)에 이르기까지 검증했던 후보입니다. 위 7·8절의 분석은 이 과정에서 수행했습니다.

## 10. 검증하지 않은 범위

- 실제 모터의 영점·축 방향·우측 체결·중립 접촉면과 등받이 좌표 정렬, 실제 지연과 부하 응답
- PWM–출력축 매핑(500~2500 µs ↔ 270°)과 혼 영점의 실물 보정
- 실기 100 Hz 압력 수집 유지율, USB·모터 부하 지연, 저장장치 지연
- 실제 충돌에서의 충격 판정 검출률
- 착좌 압박, 몸 쏠림 감소 등 지지 효과 — 정지 시트에서 가상 차량 가속도는 사람에게 실제로 가해지는 외란이 아님
- 기록 전압은 힘·압력(Pa)으로 교정한 값이 아님

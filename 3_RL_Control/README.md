# 3. 강화학습 볼스터 제어 (RL Control)

> 좌·우 볼스터의 목표 각도를 정하는 **제어기의 두뇌**입니다.

## 제어기는 어떻게 결정하나

### 1. 입력 — 관측 57개 × (현재 + 과거 8틱)

| 구분 | 내용 |
|---|---|
| 예측 횡가속도 10개 | 0.1 ~ 1.0초 뒤 횡가속도 (아래 예측기) |
| 차량 상태 | 횡·종가속도, 요레이트, 속도, 조향 |
| 압력 | 측면 패드 4개, 등판 2, 좌판 2, 좌우 차이 4 (세션 시작 대비) |
| 볼스터 상태 | 보드가 보고한 좌·우 yaw/pitch, 직전 행동 |
| 체형 | 질량, 어깨 폭, 앉은키, 측면 패드 휴지 압력 |
| 유효성 | 자세 데이터 나이, 압력 유효, 인터락 상태 |

### 2. 1초 횡가속도 예측기
핸들 각·조향 속도로 정상상태 횡가속도를 계산하는 물리 기반 예측에, 31 → 64 → 64 → 10 MLP가 잔차를 더합니다.

| 예측 시간 | 0.1 s | 0.5 s | 1.0 s |
|---|:---:|:---:|:---:|
| **예측기** | 0.023 g | 0.054 g | **0.090 g** |
| 현재 값 유지 | 0.034 g | 0.088 g | 0.140 g |

서보가 느리기 때문에(실효 yaw 약 5 ~ 6 °/s) 미리 움직이는 것이 성능을 좌우합니다. 관측 제거 실험에서도 이 예측을 빼면 점수가 가장 크게 떨어졌습니다.

### 3. 튜닝 규칙 + SAC 잔차 정책
- **튜닝 규칙:** `밀릴 쪽 볼스터 = min(10°, 160°/g × |0.7초 뒤 횡가속도|)`, 반대쪽은 0°. 72개 격자 탐색으로 정했습니다.
- **SAC 정책:** 513 → 256 → 256 → 2 MLP. 튜닝 규칙에서 출발해 **±0.25 범위의 보정만** 학습합니다.
- **보상 = 평가 점수:** 상체 흔들림(CoM RMS) 감소율 − 과도한 압박(20 N 초과) 벌점. 학습 목표와 평가 기준을 같게 맞췄습니다.
- **행동 → 각도:** `[공통, 좌우 차등]` 두 값을 좌·우 yaw 목표 0 ~ 20°로 변환합니다.

### 4. 실물 제어 법칙: G 기본 곡선 + RL 보정
실제 착석 시험에서는 학습 정책을 그대로 쓰지 않고, 측정 횡가속도 기반 기본 곡선에 RL 보정을 제한적으로 더했습니다(`deploy/runtime/oasis_rt/g_residual_control.py`).

```text
기본각    |G| 0.01 g → 0°,  0.0625 g → 10°,  1 g → 20°   (구간 선형)
예측만    최대 10°, 100 ms 확인 후 적용
RL 보정   (정책 각도 − 학습 기준 규칙 각도), 최대 ±1.5°, 1 g에서 0°로 축소
```

### 5. 체형 스케일 (v9)
카메라 중립 자세에서 잰 어깨 폭을 기준 사용자와 비교해 기본각을 0.9 ~ 1.1배 합니다(`oasis_rt/body_scale.py`).

```text
s = clip(1 − 1.2 × (어깨 폭 비 − 1), 0.9, 1.1)
```

넓은 체형은 예압이 커서 일찍 닿으므로 덜 조이고, 좁은 체형은 틈이 있어 더 조입니다. 기본은 꺼져 있으며(s = 1), 켜면 세션마다 한 번 계산해 고정합니다.

### 6. Fallback
| 상황 | 동작 |
|---|---|
| 정책 추론 실패 (예외, NaN) | 튜닝 규칙으로 전환, 세션 끝까지 유지 |
| 모델 패키지 없음 · 해시 불일치 | 백업 제어기(`4_Seat_Actuation/experiment_a`)로 세션 진행 |
| 입력·보드 오류, 충격 의심 | 즉시 PWM OFF 후 종료, 자동 재시작 없음 |

## 결과

### 시뮬레이션 (평가용 48개 에피소드, 같은 에피소드 비교)

| 제어기 | 종합 점수 J ↑ | 흔들림 감소 (L0 / L2) | 20 N 초과 압박 시간 (L0 / L2) | 규칙 대비 우세 |
|---|:---:|:---:|:---:|:---:|
| **RL 정책 (배포)** | **3.92** | 8.1 / 10.1 % | 4.8 / 6.9 % | 32 / 48 |
| 튜닝 규칙 | 3.93 | 9.8 / 10.8 % | 4.9 / 7.5 % | — |
| 백업 제어기 | 1.70 | 3.5 / 4.4 % | 2.2 / 2.9 % | 10 / 48 |

- RL 정책은 튜닝 규칙과 같은 수준이고, 백업 제어기보다 분명히 낫습니다.
- 4개 학습 시드 중 검증과 평가 모두에서 규칙 이상인 시드(`v8_s1`)를 배포했습니다.

## 재현

```bash
source sim/v3/final/env.sh          # 최종 환경 (보정값 + overlay 체인)
bash sim/v3/final/run_final.sh      # 예측기 → 감사 → 규칙 → SAC → 검증 선택 → 평가 → 내보내기 → 시험 → 관측 제거 → 체형

# GPU 학습 (4 시드)
OASIS_TRAIN_PY=<CUDA torch python> OASIS_SEEDS="0 1 2 3" OASIS_TRAIN_THREADS=2 bash sim/v3/final/run_final.sh

# 체형 스케일 튜닝·검증
python sim/v3/tune_body_scale.py --runtime deploy/runtime --out results/v9/body_scale.json --csv <episodes.csv>
python sim/v3/tune_body_scale.py --runtime deploy/runtime --validate -1.2 0 0.9 1.1 --out results/v9/body_scale_validation.json

# Pi용 모델 패키지
python deploy/tools/pack_model.py deploy/model_v8
```

- 시드당 200k 스텝, GPU(RTX 4070 SUPER, 4개 동시)에서 약 1시간 걸립니다.
- 실차 기반 입력 시퀀스는 `python sim/v2/make_l1_seq.py`로 정제 데이터에서 만듭니다.
- 학습 데이터, 체크포인트, 모델 가중치는 저장소에 포함하지 않습니다.
